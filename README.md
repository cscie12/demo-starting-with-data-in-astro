# Starting with Data in Astro

Data handling and dynamic routes in Astro.

## Examples

Each folder demonstrates a concept:

- **v1** (`/apples`): Dynamic routing with hardcoded data in `getStaticPaths()`.
- **v2** (`/apples2`): Extract data into a separate array, loop it in `getStaticPaths()`.
- **v3** (`/apples3`): Import JSON data for both the index list and page generation.
- **v4** (`/apples4`): Use richer data and pass additional properties to pages via `props`.
- **v5** (`/apples5`): Reusable components with passed data and CSS Grid styling.

## Quick Start

```
npm install
npm run dev
```

Visit `localhost:4321` to view.
